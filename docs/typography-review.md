# SUIT 적용 기록

사이트 기본 글꼴을 SUIT Variable 2.0.5로 변경했습니다. 공식 배포본 WOFF2(624,536 bytes)를 수정 없이 `public/fonts/suit/`에 포함했으며 라이선스 전문과 출처를 함께 보관합니다. 공통 글꼴은 외부 Google Fonts 요청 없이 로드하고 첫 화면에서 미리 불러옵니다.

- 기본 본문: 16px / 굵기 450 / 줄 높이 1.7 / 자간 -0.01em.
- 기존 제목의 크기와 굵기를 유지하면서 한글·영문·숫자를 SUIT로 통일했습니다.
- 입력창·선택창·버튼도 글꼴·굵기·자간을 상속합니다. 개별 컴포넌트의 명시적 굵기는 유지합니다.
- 의류 쇼핑몰의 별도 글꼴 설정도 통일하고, 작은 화면에서 할인 가격이 줄바꿈되도록 조정했습니다.
- 스튜디오 데모는 본문에 SUIT를 사용하고, 영문 장식 글꼴은 유지하면서 한글 대체 글꼴에 SUIT를 지정했습니다.

검증: 프로덕션 빌드·타입 검사 통과. 홈·서비스·가격·상담·회사소개·프로젝트 및 의류·화장품·부동산·스튜디오 데모를 1440/768/390/360px에서 확인했습니다. 40개 화면 조건에서 SUIT 로딩과 가로 넘침 없음을 확인했고, Chrome의 실제 사용 글꼴 정보에서 한글·영문·숫자가 SUIT로 렌더링됨을 확인했습니다. 모바일의 목적별 설명 모달 3개에서 링크 표시와 Escape 닫기도 확인했습니다.
