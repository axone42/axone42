# 고객 경험 개선 검토

브랜치: `feat/customer-experience-review`

## 변경 사항

- 홈을 업무 자동화 / 웹·시스템 구축 / 컨설팅·교육의 세 가지 목적 중심으로 구성했습니다. 자체 데모를 직접 체험할 수 있고, 상담 이후 진행 과정도 안내합니다.
- 샘플 고객명·후기·성과 수치를 제거하고 자체 구현 예시임을 표시했습니다. 프로젝트 22개를 중복 없이 보여주며 체험 가능한 데모 19개를 따로 필터링합니다.
- 서비스별 기존 기준 금액을 유지하면서 초기 구축비와 월 운영·대행료를 분리했습니다. 서비스 추가 시 총액이 오히려 낮아지던 일괄 20% 할인은 제거했습니다. 무료 상담과 500만원 유료 진단·로드맵의 범위를 구분했습니다.
- 가격 항목마다 제공 내용과 상담에서 확정할 범위를 표시합니다. 회차당 시간·인원·수정 횟수·부가세 등 아직 확정되지 않은 정책을 임의로 약속하지 않습니다.
- 상담 선택 목록은 접어서 입력란을 먼저 보여줍니다. 12개 서비스의 상담 연결을 정확한 ID로 매핑하고 두 교육 과정의 문의 맥락을 보존합니다.
- 필드별 입력 오류, 중복 제출 방지, 실패 시 입력 보존을 구현했습니다. 서버가 금액을 다시 계산하며 메일 설정 누락이나 전송 실패를 성공으로 처리하지 않습니다.
- 문서 데모는 실제 TXT, OCR 데모는 샘플 CSV 다운로드를 제공합니다. HWP/HWPX 파일 생성은 지원하지 않는다고 명시합니다. n8n의 가상 임포트는 현재 화면의 검토 목록으로 변경했습니다.
- 주식 시세에 더하던 무작위 변동을 제거했습니다. 조회한 시세만 표시하고 예시 보유 내역과 데이터 지연 가능성을 안내합니다.

## 확인 동선

1. 홈에서 세 목적별 서비스로 이동하고 서비스 상세 → 상담 신청을 확인합니다.
2. 가격에서 홈페이지 + AI 자동화 + 마케팅을 선택합니다. 초기 5,000,000원부터 / 월 1,700,000원으로 구분됩니다. 상담에 세 항목이 전달되는지 확인합니다.
3. AI 자동화 강의와 바이브코딩 강의에서 각각 상담을 열어 교육 과정명이 유지되는지 확인합니다.
4. 모바일에서 상담 입력란과 메뉴, 가격 선택·비용 확인·상담 버튼을 확인합니다.
5. 프로젝트의 데모 필터와 문서 TXT / OCR CSV 다운로드, n8n 검토 목록을 체험합니다.

## 검증 기록

- `npm test`: 핵심 회귀 테스트 6개 통과. 비용 분리·금액 역전 방지·12개 서비스 매핑·메일 미설정/실패·잘못된 요청·서버 금액 재계산을 검증합니다.
- `NEXT_DIST_DIR=.next-review` 환경에서 `npm run build`: 프로덕션 빌드와 타입 검사 통과.
- Chrome headless 실제 브라우저: 주요 6개 페이지, 12개 서비스 상세 클릭과 상담 선택, 입력 검증, 실패 시 보존·성공 시 초기화, TXT/CSV 다운로드, n8n 목록, 프로젝트 22개/데모 19개 필터를 확인했습니다.
- 320 / 390 / 768 / 1440px에서 홈·가격·상담·프로젝트 페이지의 가로 넘침이 없었습니다. 390px에서 상담 이름 입력란은 페이지 상단 기준 약 633px입니다.
- 시세 응답을 고정한 브라우저 테스트에서 대기 중 및 차트 기간 변경 후 현재가가 유지됨을 확인했습니다.
- 상담 API 브라우저 테스트는 응답을 가로채고 서버 테스트는 메일 전송기를 모의 처리했습니다. 실제 메일 발송·수신이나 운영 외부 서비스 연동은 이번 검증에 포함하지 않았습니다.

## 로컬 미리보기

PowerShell:

```powershell
$env:NEXT_DIST_DIR='.next-review'
npm run build
npm run start -- --port 3002
```

http://localhost:3002 에서 확인합니다. 기존 개발 서버의 `.next`와 빌드 결과를 분리합니다.

기존 작업 중이던 가격·상담 변경을 보존해 통합했습니다. `.claude/`, `scripts/`, `명함/`은 이번 변경에 포함하지 않습니다. 이 브랜치는 프로덕션에 배포하거나 main에 병합하지 않았습니다.
