# 데모 사진 적용 기록

내장 `image_gen`으로 44장의 사진을 생성하고 `public/lab-img/`에 WebP로 저장했습니다. 전체 파일 용량은 약 2.02MiB이며 외부 이미지 호스팅에 의존하지 않습니다. 파일별 최종 프롬프트와 크기는 `demo-image-prompts.json`에 기록했습니다.

| 데모 | 이미지 | 적용 위치 |
| --- | --- | --- |
| 의류 쇼핑몰 | 메인 1장 + 상품 10장 | 메인, 상품 목록·상세, 룩북 띠, 코디 추천, 위시리스트, 장바구니 |
| 화장품 쇼핑몰 | 메인 1장 + 상품 10장 | 메인, 상품 목록·상세, 장바구니 |
| 크리에이티브 스튜디오 | 메인 1장 + 작품 12장 + 인물 6장 | 메인, 작품 릴·목록·상세, 팀 소개 |
| 부동산 수집 | 공간 예시 3장 | 매물 카드의 썸네일 |

메인 사진은 우선 로드하고, 다른 사진은 지연 로드합니다. 이미지가 실패하면 기존 대체 화면을 표시합니다. 쇼핑몰 두 곳의 메인 사진을 모바일에서도 볼 수 있도록 레이아웃을 조정했습니다.

AI 생성 예시 이미지임을 데모 안내에 명시했습니다. 부동산 카드에는 실제 매물 사진으로 오인하지 않도록 개별 표시도 추가했습니다. 의류의 색상 옵션은 대표 사진을 공유합니다.

확인 결과:

- 프로덕션 빌드 및 타입 검사 통과.
- 데스크톱에서 의류·화장품·스튜디오의 이미지 로딩 및 화면 구성을 확인.
- 390px / 768px에서 세 데모의 메인 사진 표시 및 가로 넘침 없음 확인.
- 의류 사이즈 선택 → 담기 → 상세 닫기 → 장바구니 사진 표시 확인.
- 화장품 상세 → 담기 → 장바구니 사진 표시 확인.
- 스튜디오 STUDIO 메뉴 → 팀 사진 6개, 부동산 카드 사진 로딩 확인.

같은 브랜치의 홈 변경: 세 목적별 카드는 설명 모달을 먼저 열고 서비스·가격 버튼을 눌러 이동합니다. Escape·닫기·배경 클릭으로 닫으며 카드 포커스와 홈 스크롤 위치를 유지합니다. 브라우저에서 세 모달, 모바일 크기, 서비스 링크, 가격 이동을 확인했습니다.
